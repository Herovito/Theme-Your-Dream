De site op branch `concept-site` bevat placeholders die er echt uitzien maar het niet zijn:

- WhatsApp: `wa.me/31612345678` — verzonnen nummer, staat in alle CTA's
- Footer: `KvK: xxxxxxxx` / `Btw-id: NLxxxxxxxxxBxx`
- Privacyverklaring: `KvK nummer: [in te vullen]`
- Themabox-prijzen (vanaf €75 t/m €90, borg €35/€40, verhuurperiode 3 dagen) zijn **niet geverifieerd** als door Dionne goedgekeurde prijzen
- Geen portfolio, geen reviews, geen testimonials aanwezig

**Why:** Het is een conceptsite die bewust op `noindex, nofollow` staat tot livegang. Deze cijfers zijn ingevuld om het ontwerp te kunnen beoordelen, niet omdat ze kloppen.

**How to apply:** Behandel deze waarden nooit als bron. Gebruik ze niet in structured data, GBP-adviezen of metadata. Zet ze op de lijst "feiten die nog moeten worden aangeleverd" in elke briefing. Controleer bij een nieuwe opdracht eerst of ze inmiddels wel zijn ingevuld — deze memory kan verouderd zijn.
